## 名词速查

| 名词 | 英文 / 缩写 | 一句话解释 |
| --- | --- | --- |
| 目标车型 | target class | 本组从 827 类中选出的 50 个车型类别 |
| unknown | 未知类 | 第 51 类，表示"不属于本组所选 50 类的其他车型" |
| 类别索引 | class index | 模型输出的下标 0~50；0~49 按 `classes.txt` 行序对应 50 个车型，50 固定为 unknown |
| 类别 ID | class id | 教师给定的四位数字（如 `0003`），保留前导零 |
| 标签名 | label name | `class_info.json` 的 `name_from_new` 字段，如 `宇通客车_宇通T7` |
| Macro-F1 | 宏平均 F1 | 先算每类 F1 再对 51 类**等权平均**；本任务唯一的评分指标 |
| 混淆矩阵 | confusion matrix | 51×51 表，第 i 行 j 列 = 真实类 i 被判成类 j 的张数 |
| TTA | Test-Time Augmentation | 推理时对同一张图做多种变换，把结果平均 |
| EMA | Exponential Moving Average | 对模型权重做指数滑动平均，用平滑后的权重评估 |
| MixUp / CutMix | — | 把两张图（或两块区域）按比例混合，抑制过拟合 |
| RandAugment | — | 从一组图像操作里随机挑 N 个、以固定强度施加 |
| 先验校正 | prior adjustment | 推理时把训练集类别先验从 logits 中减掉，公式 `z' = z − τ·log(π)` |
| 拒识阈值 | rejection threshold | `max(softmax) < t` 时把预测改写为 unknown |
| τ（tau） | prior adjust strength | 先验校正强度，本项目最终取 `+0.05` |
| t | threshold | 拒识阈值，本项目最终取 `0.25` |
| 已知类误拒率 | known false-reject rate | 真实是已知车型、却被判成 unknown 的比例 |
| unknown 检出率 | unknown detection rate / recall | 真实是 unknown、且被正确判成 unknown 的比例 |
| 集成 | ensemble | 多个模型的概率平均，本项目把 C1 与 C2 做几何平均 |
| C1 / C2 / C3 | — | 实验代号：C1=ResNet18@224，C2=ResNet50@224，C3=C1+C2 集成 |

## 项目一句话总结

从教师提供的 **827 个车型类别**中自主选出 **50 类**（覆盖 37 个品牌、6 种车身大类），
从组外类别构造 **unknown** 训练/验证样本，训练一个 **51 类**图像分类模型，
在验证集上取得 **Macro-F1 = 0.9604**（基线 0.8475，提升 +0.1092），
并以标准化格式输出 `classes.txt` 与 `predictions.csv`。

**全部训练在纯 CPU（AMD Ryzen 9 7940H）上完成**，总训练耗时约 5.4 小时。
