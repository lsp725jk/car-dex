# 01 项目总览与快速开始

## 1. 项目是什么

**识车档案 CarDex** —— 面向私人用户的车型资料库。

用户拍一张车照上传，系统需要回答的不是"这是一辆 SUV"，而是：
1. 这具体是哪一款车型（50 个目标车型之一，还是**不在我资料库里的车**）；
2. 它的档案（品牌、车身形式、同级定位、看点）；
3. 把它写进我的「看车档案」，以后能按品牌 / 车身类型 / 时间检索。

因此视觉识别的结果必须**参与后续业务**：识别出的 `车型ID + confidence` 会作为工具返回值传给
DeepSeek-V4-Flash 智能体，驱动「档案查询 → 写入记录 → 检索个人车库」这条链路。

本文档覆盖的是**任务一**：把那个"看得懂车型、也敢说看不懂"的视觉模型做出来。

### 1.1 视觉任务的精确定义

| 项目 | 内容 |
| --- | --- |
| 输入 | 一张车辆照片（任意尺寸、任意角度、任意背景） |
| 输出 | `车型ID`（四位数字，来自 `classes.txt`）**或** `unknown`，外加 `confidence` |
| 输出类别数 | **51** = 50 个自主选择的车型 + 1 个 unknown |
| 评分指标 | **51 类等权 Macro-F1**（任务书 4.3 节规定，唯一评分指标） |

### 1.2 为什么 unknown 是一等公民

私人用户随手拍到的车，大概率**不属于他自己选的 50 款**。
如果模型强行给出一个已知车型，后续的"档案查询 → 写入记录"就会写入错误数据，比"不认识"更糟。

而 Macro-F1 对 unknown 与每个目标车型**等权**（各占 1/51），所以：
- 漏报 unknown（把组外车型硬认成某个已知车型）→ unknown 的 Recall 下降；
- 误拒（把已知车型判成 unknown）→ 对应车型的 Recall 下降。

两种错误都会直接扣分。本项目最终的 unknown F1 = **0.912**，是全部 51 类里的中游水平。

> 通过"线程数调优 + bf16 混合精度"把单轮训练从 4.3 分钟压到 1.8 分钟，
> 才使 5 组实验矩阵可以在可接受时间内跑完。

### 4.3 预训练权重（关键，容易踩坑）

本项目只使用 torchvision 官方 ImageNet 预训练权重，**必须已存在于本地缓存**
`%USERPROFILE%\.cache\torch\hub\checkpoints\`：

| 文件名 | 对应枚举 | 是否被本项目使用 |
| --- | --- | --- |
| `resnet18-f37072fd.pth` | `ResNet18_Weights.IMAGENET1K_V1` | ✅ 基线 / B / C1 |
| `resnet50-0676ba61.pth` | `ResNet50_Weights.IMAGENET1K_**V1**` | ✅ C2 |
| `wide_resnet50_2-9ba9bcbe.pth` | `Wide_ResNet50_2_Weights.IMAGENET1K_V2` | ❌ 未用，但已缓存 |
| `resnet50-11ad3fa6.pth` | `ResNet50_Weights.IMAGENET1K_**V2**` | ❌ **不要用**，本地没有会触发联网下载 |

> ⚠️ **踩坑记录**：`ResNet50_Weights` 有 V1 与 V2 两个版本，文件名不同。
> 如果代码写成 `IMAGENET1K_V2`，torchvision 会去下载 `resnet50-11ad3fa6.pth`，
> 在无网环境下直接抛 `RuntimeError`。本项目在 `src/cardex/models.py` 里固定使用 V1 并有注释提醒。

## 6. 完整复现命令

从零开始（假设教师数据集的 zip 已在 `C:\Users\y\Downloads\数据集.zip`）：

```bash
# ---------- 阶段 1：数据准备 ----------
python src/inventory.py            # 只读 zip 中央目录，统计 827 类的样本量与品牌/车型分布
python src/list_candidates.py      # 生成候选类别明细表（便于人工挑类）
python src/select_classes.py       # 依 configs/selection.json 选出 50 类
                                   #  → classes.txt / class_map.json / unknown_sources.json / 选类报告
python src/prepare_data.py         # 从 6.6 GB zip 中只抽 9916 张需要的图到 data/
python src/data_analysis.py        # 数据集分析：类别分布、尺寸、重复检测、unknown 构成、样例九宫格

# ---------- 阶段 2：训练 5 组实验 ----------
python src/train.py --config configs/train_baseline.json       # A  基线        ~28 min
python src/train.py --config configs/train_weighted.json       # B  类别平衡    ~32 min
python src/train.py --config configs/train_improved.json       # C1 改进        ~87 min
python src/train.py --config configs/train_improved_r50.json   # C2 骨干容量    ~175 min

# ---------- 阶段 3：评估与标定 ----------
python src/evaluate.py --checkpoint outputs/checkpoints/improved_resnet50_224/best.pt --tta-hflip
python src/calibrate.py --run improved_resnet18_224 --tta-hflip
python src/calibrate.py --run improved_resnet50_224 --tta-hflip
python src/visualize_errors.py --run improved_resnet18_224 --class-id 0975

# ---------- 阶段 4：选冠军并生成交付物 ----------
python src/finalize.py --candidates improved_resnet18_224 improved_resnet50_224 \
       --ensembles improved_resnet18_224+improved_resnet50_224
#  → 自动比选 C1 / C2 / C1+C2，选出冠军，重生成 predictions.csv

# ---------- 阶段 5：汇总与校验 ----------
python src/make_reports.py         # 实验对比表 + 训练曲线 + 混淆矩阵热力图 + 逐类 F1 条形图
python src/score_predictions.py    # 用本地真值独立核算 predictions.csv 的 Macro-F1
python src/verify_reload.py --checkpoint outputs/checkpoints/improved_resnet50_224/best.pt \
       --n 240 --tta-hflip --out outputs/runs/reload_a.json
python src/verify_reload.py --checkpoint outputs/checkpoints/improved_resnet50_224/best.pt \
       --n 240 --tta-hflip --out outputs/runs/reload_b.json
python src/verify_reload.py --compare outputs/runs/reload_a.json outputs/runs/reload_b.json
python src/verify_submission.py    # 41 项提交前自查
python src/final_check.py          # 交付物总览

# ---------- 阶段 6（可选）：生成 HTML 说明文档 ----------
python tools/build_docs_html.py
```

## 8. 你应该先做的两件事

### 8.1 `predictions.csv` 需要重跑（重要）

当前 `predictions.csv` 是**对本地 `data/val`（2,422 张）生成的演练版本**，
因为教师指定的测试图片目录**尚未下发**（教师提供的压缩包内只有 `train/` 与 `val/`，没有 `test/`）。

拿到教师指定的测试目录后，执行一次即可，其余参数（模型、标定、TTA）**都不需要改**：

```bash
# 方式一：沿用最终集成配置（推荐）
python src/finalize.py --candidates improved_resnet18_224 improved_resnet50_224 \
       --ensembles improved_resnet18_224+improved_resnet50_224 \
       --split val            # ← 若要对外部目录推理，改用下面的方式二

# 方式二：直接对目录批量推理
python src/predict_batch.py \
       --checkpoint outputs/checkpoints/improved_resnet50_224/best.pt \
       --input-dir <教师指定测试图片目录> \
       --output predictions.csv \
       --tta-hflip
```

> 注意：`predict_batch.py` 用**单模型**，`finalize.py` 用**集成**。
> 如果教师要求提交最高分结果，应使用集成（`finalize.py` 会默认写 `predictions.csv`）。

### 8.2 `classes.txt` 需要与教师登记版本核对

自动化脚本只能验证：
- 文件名、编码（UTF-8 无 BOM）、行数（恰好 50）、ID 格式（四位数字）、唯一性、升序；
- 全部 ID 属于教师提供的 827 类。

**无法验证**的是"与教师侧登记的最终版本是否一致"——这一条需要人工确认（任务书自查清单明确要求）。
