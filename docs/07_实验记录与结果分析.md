## 0. 实验设计

### 0.1 实验矩阵

| 代号 | run_name | 目的 | 相对上一组改变的**唯一变量** |
| --- | --- | --- | --- |
| **A** | `baseline_resnet18_160` | 建立 51 类分类基线 | — |
| **B** | `weighted_resnet18_160` | 隔离"类别不平衡处理"的贡献 | `class_weight: none → inverse` |
| **C1** | `improved_resnet18_224` | 检验"分辨率 + 强正则化"的组合收益 | `image_size 160→224`，增强轻量→强，+EMA，+MixUp/CutMix，+标签平滑，+TTA |
| **C2** | `improved_resnet50_224` | 隔离"骨干容量"的贡献 | `arch: resnet18 → resnet50` |
| **C3** | C1+C2 集成 | 检验集成的贡献 | 把 C1 与 C2 做几何平均 |

**共同前提**：数据完全相同（train 7,494 / val 2,422）、随机种子 42、
优化器 SGD（momentum 0.9，nesterov）、weight_decay 1e-4、`head_lr_mult=1.0`、
梯度裁剪 5.0、batch size 32、余弦退火 + 线性 warmup、`threads=12`、`amp=true`。

### 0.2 关于变量隔离的诚实说明

- **A → B 是干净的**：只有 `class_weight` 一个变量。
- **A → C1 不是单变量**：同时改了分辨率、增强、损失、EMA、TTA 共 5 项。
  这是**有意为之**——本项目算力有限（纯 CPU），无法为每项各跑一次完整训练。
  报告中的表述是"组合改进的收益"，而不是"分辨率的收益"。
- **C1 → C2 是干净的**：只有 `arch` 一个变量（但 epochs 不同，见 0.3）。
- **C2 → C3 不是训练**：只是在已有模型上做概率平均，不涉及重新训练。

### 0.3 关于 epochs 不同

C1 用 18 轮、C2 用 14 轮，**不是刻意的对照设计**，而是算力约束下的取舍：
ResNet50@224 单轮约 12.5 分钟（C1 仅 4.6 分钟），18 轮需要 3.75 小时。

**但两者可以直接公平比较**：因为 `checkpoint_interval=3`，
两个 run 都保存了 `epoch_03/06/09/12.pt`，可以逐轮对齐比较。

| epoch | C1 (ResNet18) | C2 (ResNet50) | 差值 |
| --- | --- | --- | --- |
| 3 | 0.2998 | 0.4645 | +0.1647 |
| 6 | 0.8211 | 0.8719 | +0.0509 |
| 9 | 0.9099 | 0.9282 | +0.0183 |
| 12 | 0.9387 | 0.9530 | +0.0143 |
| 最终 | **0.9482 (ep18)** | **0.9550 (ep14)** | +0.0068 |

**结论**：ResNet50 在同一轮次上始终领先，但领先幅度随训练推进迅速收窄
（第 3 轮 +0.165 → 第 12 轮 +0.014）——说明**容量优势主要体现在收敛速度上，而不是最终上限**。

## 3. 实验 B：类别平衡损失（ResNet18@160，inverse）

### 3.1 配置差异

**唯一区别**：`class_weight: "none" → "inverse"`。

逆频率加权公式（`src/cardex/engine.py`）：

```python
counts = 每类训练样本数（unknown=1960，目标车型≈80~186）
w_c = counts.sum() / (num_classes * counts)      # = N / (C · n_c)
w_c = w_c / w_c.mean()                           # 归一化
```

**实际权重**（训练日志原文）：

```
类别权重已启用（inverse）：unknown=0.057  min=0.057  max=1.391
```

也就是说，unknown 的**每样本**权重被压到 0.057，
而样本最少的类别拿到 1.391 —— 使**每个类别对总损失的贡献相等**。

| Accuracy | 0.8287 | 0.8105 | −0.0182 |

### 3.4 这个实验说明什么（重要）

**类别平衡确实做到了它该做的事**：已知类误拒率从 10.3% 降到 4.7%，
即"目标车型被误判为 unknown"的情况减少了一半以上。这正是类别平衡的预期效果。

**但它同时严重伤害了 unknown 的检出率**（82% → 59%），净效果反而略差。

**为什么**：逆频率加权假设"每个类别的样本量差异是问题"，
但在本任务中，unknown 的**类内异质性极高**（它是 98 个来源车型的并集），
样本量的优势恰好补偿了学习难度。强行把它压到"和单个车型一样重"，
等于让模型对 unknown 学得不够，于是不敢说不认识。

**关键发现在第 6.2 节**：对 B 模型再做一次**负向**先验校正（τ = −0.40），
可以把丢掉的 unknown 召回找回来，同时保留它对已知类的改善：

| 配置 | Macro-F1 |
| --- | --- |
| B 未标定 | 0.8428 |
| B + τ=−0.40 仅先验校正 | **0.8545** |
| **B + (τ=−0.40, t=0.50)** | **0.8597** |
| A 基线 + 最优标定 | 0.8512 |

**结论**：**训练时的类别权重与推理时的先验校正是同一件事的两端**。
类别平衡不应该"只在训练时做一次"，而应该与推理端的 τ 联合调优。

> 这也是为什么 C1/C2 最终选择了 `class_weight: none`——
> 基线的先验扫描显示 τ=0 处 Macro-F1 最高，说明无权重模型的隐式先验恰好是最优的。
> 这是一个**数据驱动的决策**，不是照搬经验。

**显著难于**验证时的干净图片分布。

> **在强增强配方下，必须用验证集 Macro-F1 而不是训练准确率来判断模型好坏。**

说明"敢于说不认识"这个能力是**随着模型对车型特征理解加深而自然获得的**，
不是靠阈值调出来的。

## 6. 实验 C3：集成（C1 + C2）

### 6.1 方法

对两个成员的 **log-softmax 取算数平均**（等价于概率的几何平均），
再做先验校正与 softmax：

```python
adj_m = log_softmax(model_m(x)) − τ · log(π)      # 每个成员
ens   = mean(adj_1, adj_2)                        # 几何平均
probs = softmax(ens)
index = argmax(probs);  if max < t: index = unknown
```

### 6.2 结果

| 候选 | 未标定 Macro-F1 | 最优 τ | 最优 t | **标定后 Macro-F1** |
| --- | --- | --- | --- | --- |
| **C1 + C2 集成 ★** | 0.9587 | +0.05 | 0.25 | **0.9604** |
| C2 单模型 | 0.9550 | −0.20 | 0.20 | 0.9592 |
| C1 单模型 | 0.9482 | +0.10 | 0.20 | 0.9510 |

**集成带来的净收益**：相对 C2 单模型 **+0.0012**（标定后）。
很小，但稳定为正。

### 6.4 一个反向的对照实验：集成并非总是有效

我还做了一次"有害集成"的对照：把 **C1（0.9482）+ 基线（0.8475）** 做软投票。

| 配置 | Macro-F1 |
| --- | --- |
| C1 单模型 | **0.9482** |
| C1 + 基线 集成 | **0.9152** ❌ |

**集成反而掉了 0.033。**

**原因**：两个成员差距过大（0.948 vs 0.847），弱成员的噪声投票会**稀释**强成员的判断。

**结论：集成只在成员水平相近时才有效。**
这就是为什么本项目的候选集只包含 C1、C2 与 C1+C2，不再纳入基线或类别平衡模型。

## 8. 错误分析

### 8.1 主要错误模式：高置信度地把已知车型判成 unknown

从 `error_samples.csv` 中筛出错误样本，会看到一个反直觉的现象：

```
日产_轩逸  →  unknown   conf = 0.991
日产_轩逸  →  unknown   conf = 0.987
大众_朗逸  →  unknown   conf = 0.975
日产_轩逸  →  unknown   conf = 0.969
大众_朗逸  →  unknown   conf = 0.960
日产_轩逸  →  unknown   conf = 0.941
日产_轩逸  →  unknown   conf = 0.927
```

模型**以 0.99 的置信度**把一辆轩逸判成"不认识"。
这不是"不确定"，而是"非常确定地认错"。

**因此降低置信度阈值完全无法修复这类错误** —— 这解释了 6.3 节里阈值收益极小的原因。

### 8.2 根因：数据集中同一车型名下有多个世代，且划分未按世代分层

用 `src/visualize_errors.py` 把训练集样例与被误判的验证集样例并排展示
（输出：`outputs/reports/error_case_0975.png`、`error_case_0035.png`）：

**`0975 日产_轩逸`**
- **训练集样本**是**经典轩逸（B17 世代）**：圆润车身、V 型镀铬格栅与大灯一体；
- **被误判的验证集样本**是**第 14 代轩逸（2020 年后）**：V-Motion 2.0 大嘴格栅、
  细长灯组、低趴车身。
- 两者放在一起，**除了车标几乎没有共同特征**。

**`0035 大众_朗逸`**
- **训练集**是 **2018 年后的全新朗逸（Plus）**：宽横向镀铬格栅；
- **被误判的验证集样本**是 **2013–2017 经典朗逸**（窄格栅、老款大灯），
  甚至还有一辆**出租车涂装的绿色朗逸**。

**这不是模型能力问题，而是标注粒度问题。**

教师数据集用"车型名称"作为类别标签，但同一个车型名称在中国市场往往对应
**跨越 10 年、外观完全不同的多个世代/改款**。
教师按类别随机分层划分 train / val（各类 val/train 比例稳定在 0.331），
**没有按世代分层**，于是出现了"训练集全是老款、验证集有新款"的情况。

### 8.3 量化影响

| 模型 | 轩逸 → unknown | 朗逸 → unknown | unknown 检出率 | 已知类误拒率 |
| --- | --- | --- | --- | --- |
| A 基线 | 13 次（**37.1%**） | 9 次（25.0%） | 0.8197 | 0.1031 |
| C1 改进 | 7 次（20.0%） | 7 次（19.4%） | 0.9184 | 0.0398 |
| C3 最终 | — | 5 次（14%） | 0.9286 | 0.0344 |

### 8.4 强增强与高分辨率对这类错误的部分修复

C1 相对基线：轩逸的错误从 13 个降到 7 个、朗逸从 9 个降到 7 个，
unknown 检出率从 82% 提到 92%，已知类误拒率从 10.3% 降到 4.0%。原因：

1. **高分辨率**让"车标 + 格栅细节"变得可辨，模型可以抓住跨世代不变的品牌/车型线索；
2. **强增强**（大范围随机裁剪 + 颜色抖动 + RandAugment + 随机擦除）
   使模型不再依赖"某一世代特有的车身线条"，被迫学习更抽象、更跨世代不变的特征——
   这恰好对应 `RandomResizedCrop(scale=(0.50,1.0))` 让模型经常"只看到车头或车尾的一部分"。

**但这类错误没有也不可能被完全消除**，因为它本质上是数据标注粒度的问题。

### 8.5 其他典型错误

两个模型各自最严重的混淆对对比：

| 基线 A：真实 → 预测 | 次数 | 占该类 | | 改进 C1：真实 → 预测 | 次数 | 占该类 |
| --- | --- | --- | --- | --- | --- | --- |
| 日产_轩逸 → unknown | 13 | **37.1%** | | 日产_轩逸 → unknown | 7 | **20.0%** |
| 长安_长安UNI-V → unknown | 10 | 27.8% | | 大众_朗逸 → unknown | 7 | 19.4% |
| MINI_MINI → unknown | 9 | 26.5% | | 福特_福克斯 → unknown | 6 | 16.7% |
| 大众_朗逸 → unknown | 9 | 25.0% | | 雷克萨斯_ES → unknown | 4 | 10.8% |
| unknown → MINI_MINI | 9 | — | | unknown → MINI_MINI | 5 | — |
| unknown → 比亚迪_汉EV | 8 | — | | unknown → 吉利汽车_星瑞 | 4 | — |
| 福特_福克斯 → unknown | 7 | 19.4% | | unknown → 雷克萨斯_ES | 4 | — |
| 奔驰_奔驰GLE → unknown | 7 | 17.9% | | MINI_MINI → unknown | 3 | 8.8% |

**两个模型共享同一种错误形态**：绝大多数严重混淆对都是"真实车型 → unknown"。

**次要错误类型**：

- **跨品牌同型车混淆**：基线中 `大众_朗逸 → 日产_轩逸`（置信度 0.847）、
  `日产_轩逸 → 福特_福克斯`（0.825）。同为紧凑型三厢家用车，是模型最易混淆的一组。

  原因是 unknown 的来源类别里包含与这些车型高度相似的组外车型。
- **同品牌内部混淆：几乎没有。** 因为 50 类中同品牌最多只有 2 类且形态差异极大，
  两个模型的混淆矩阵中**都没有出现同品牌内部混淆**
  （如 E 级 vs GLE、轩逸 vs GT-R 的混淆计数为 0）。这说明选类原则 P3 达到了预期效果。
