## 3 明确不提交的内容

| 内容 | 位置 | 不提交的原因 |
| --- | --- | --- |
| 模型权重与中期 checkpoint | `outputs/checkpoints/`（约 1.5 GB） | 报告模板明确说明「模型权重、中期 checkpoint 和最终模型保存在本地，用于运行系统；无需提交，也不要打包进项目源代码」 |
| 教师数据集 | `数据集/`（约 6.2 GB） | 教师提供，不应二次分发 |
| 抽取后的训练/验证数据 | `data/`（约 1.6 GB） | 可由 `src/prepare_data.py` 从数据集重新生成 |
| 扩充来源类数据集 | `data_ood/` | 硬链接构成，可由 `tools/build_ood_dataset.py` 重新生成 |
| 会话日志与工具调用流水 | `agent/data/sessions*/`、`tool_calls.jsonl`（约 16 MB） | 运行期产物，含用户对话，不属于源码 |
| **本地密钥文件** | **`agent/.env.local`** | **含真实 DEEPSEEK_API_KEY，任何情况下都不提交**（`.gitignore` 已忽略；打包脚本还会在打包前自动扫描并拦截） |
| 个人车库数据库 | `agent/data/garage.db` | 运行期数据，首次运行会自动建表 |
| 渲染预览图 | `outputs/report/preview-*/` | 检查排版用的临时产物 |
| Python 缓存 | `__pycache__/`、`*.pyc` | 可重新生成 |

## 4 收到源码后如何跑起来

```
1. 安装依赖：pip install -r requirements.txt
2. 准备模型权重：把训练好的 best.pt 放到 outputs/checkpoints/<run_name>/ 下，
   集成成员由 outputs/reports/final_model_choice.json 指定
3. 配置密钥：设置环境变量 DEEPSEEK_API_KEY，或复制 agent/.env.example
   为 agent/.env.local 并填入（该文件已被 .gitignore 忽略）
4. 启动：双击 start.bat（会自动完成环境自检并给出修复建议）
```

若只想离线验证智能体骨架而不消耗 API 额度：`python tools/verify_agent.py`（默认离线模式，124 项断言）。
