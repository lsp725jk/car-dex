4 收到源码后如何跑起来

1. 安装依赖：pip install -r requirements.txt
2. 准备模型权重：把训练好的 best.pt 放到 outputs/checkpoints/<run_name>/ 下，
   集成成员由 outputs/reports/final_model_choice.json 指定
3. 配置密钥：设置环境变量 DEEPSEEK_API_KEY，或复制 agent/.env.example
   为 agent/.env.local 并填入（该文件已被 .gitignore 忽略）
4. 启动：双击 start.bat（会自动完成环境自检并给出修复建议）

若只想离线验证智能体骨架而不消耗 API 额度：python tools/verify_agent.py（默认离线模式，124 项断言）。
