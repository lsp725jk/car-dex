# 识车档案 CarDex — 提交说明

本组提交 EduBench 车辆识别结果，包含三个必需文件。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `classes.txt` | 本组选定的 50 个车型类别 ID，每行一个四位数字，升序，UTF-8 无 BOM |
| `result.csv` | 每张测试图片的最终预测，两列：`image_id,predicted_label` |
| `result.npz` | 每张图片在 51 个类别上的完整分数，键为 `image_id` 与 `logits` |

## 方法概述

**任务一（视觉分类）**：从教师提供的 827 类中选取 50 个车型类别，
外加 1 个 `unknown` 类（由 98 个组外类别的图片构成，含 34 个刻意挑选的近似款），
共 51 类。

模型为 **ResNet50 三模型集成**，全部使用 torchvision 官方 ImageNet 预训练权重训练：

| 成员 | 输入尺寸 | 说明 |
| --- | --- | --- |
| `r50_416` | 416×416 | 高分辨率主模型 |
| `r50_288_supcon` | 288×288 | 引入有监督对比学习（SupCon），拉大类间特征距离 |
| `wide_r50_2_288` | 288×288 | Wide ResNet50_2，更大容量 |

推理时采用 **多裁剪 TTA**（中心 + 四角，各配水平翻转，共 10 个视角），
对三个成员的 log-softmax 做加权几何平均，并施加**先验校正**（τ=0.2）。
最终预测为 51 类上的 argmax。

## `logits` 的列序

`logits[i, j]` 的第 `j` 列对应：

- `j = 0..49`：`classes.txt` 的第 `1..50` 行（按行序）
- `j = 50`：`unknown`

`argmax(logits[i])` 即该图片的最终预测标签（本组拒识阈值为 0，
即由模型自身输出 unknown，不做额外阈值截断）。

## 本地验证结果

在教师提供的验证集（2,422 张；51 类）上，本方案的 51 类 Macro-F1 为 **0.9845**。
为检验是否过拟合验证集，另做了 5 折交叉验证：留出折平均 **0.9812 ± 0.0059**，
与全集标定值差 **−0.0003**。
